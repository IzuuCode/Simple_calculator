## 📖 Overview

**Simple Calculator** is a straightforward Python utility designed to handle essential arithmetic calculations directly from your terminal. Clean, fast, and dependency-free, it serves as an accessible tool for quick math operations or as a foundational Python project.

---

## 🚀 Features

| Operation | Symbol | Description |
| :--- | :---: | :--- |
| ➕ **Addition** | `+` | Computes the sum of two numbers. |
| ➖ **Subtraction** | `-` | Finds the difference between two numbers. |
| ✖️ **Multiplication** | `*` | Calculates the product of two numbers. |
| ➗ **Division** | `/` | Divides one number by another (with zero-division handling). |
